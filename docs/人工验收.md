# M2 人工验收

自动化测试覆盖了能覆盖的部分：Rust 216 项（含 3 网络 + 10 频道并发）、前端 355 项
（含一个全程不用鼠标的键盘走查）。但**没有任何像素级确认**——本机沙箱拒绝提权，
无法启动窗口截图。纯视觉的问题（间距、配色、悬停态、拥挤程度、滚动顺滑度）
只能靠这份清单来看。

建议按顺序走完；每项都写了「怎么做」和「该看到什么」。看到不符合的，记下编号即可。

---

## 0. 准备

两个终端。

**终端 1 —— mock 服务器**

```bash
pnpm mock
```

它会打印 `starting the mock IRC server on 127.0.0.1:6667`，然后一直挂着。

**终端 2 —— 客户端**

```bash
pnpm tauri dev
```

首次编译需要几分钟。窗口出现后：

1. 点左侧「添加网络」，或按 `Ctrl+K` 输入「添加网络」回车。
2. 地址填 `127.0.0.1`，端口 `6667`，**不要**勾 TLS。
3. 昵称填 `ircuit`（mock 用这个昵称组织 NAMES，用别的也能连上）。
4. 连接。

连上后服务缓冲区会滚过注册握手，然后：

```text
/join rust
```

mock 会一次性发来成员列表、格式码样例、链接样例和若干对话——M2 的渲染能力都在这一屏。

## 11. 自己的发言（两条回显路径）

自己发的消息有两条完全不同的来路，两条都要看——真实网络里两条都可能遇到。

| # | 怎么做 | 该看到什么 |
| --- | --- | --- |
| 11.1 | 停掉 `pnpm mock`，改用 `pnpm mock:no-echo`（服务器**不**提供 `echo-message`） | —— |
| 11.2 | 重新连接，`/join rust`，随便发一句话 | 消息**必须正常出现**（由客户端本地回显）。空着就说明这条路径坏了 |
| 11.3 | 同一句话检查原始流量 | 服务缓冲区的出站只有一条 `PRIVMSG`，**没有**重复的入站行 |
| 11.4 | 发一条很长的消息（超过 400 字符） | 被拆成多行发出，**每一行都出现**，不是只出现第一行 |
| 11.5 | 发 `/me 挥手` | 显示为动作，与普通消息区分得开 |
| 11.6 | 换回 `pnpm mock`（提供 `echo-message`），重连后再发一句 | 消息仍然**只出现一次**（这次是服务器回显），不能出现两条 |

> 11.1 的开关是为了这条验收加的：mock 原先无条件回显，把「服务器不回显时自己的消息
> 完全不显示」这个缺陷遮住了很久。默认的 `pnpm mock` 行为没变。

## 已知限制

- **未做 GUI 截图确认**：上面每一条都是「我预期会看到」而不是「我确认看到了」。
  首次运行时的布局问题（例如某个 `flex` 撑不开、长昵称溢出、深浅色对比度不足）
  最可能出现在这里。
- **真实网络未验证**：M1 留了一个 `#[ignore]` 的真实网络用例
  （`cargo test -p ircuit-client --test registration -- --ignored`，默认连
  `irc.oftc.net`，可用 `IRCUIT_TEST_SERVER` 等环境变量覆盖）。
  建议至少在 Libera.Chat 或 OFTC 上真实连一次，确认注册、SASL 之外的
  常规握手、以及中文频道的显示。
- **重启不保留任何会话状态**：M2 的历史只存在内存里，这是 M3 的内容。
- **桌面通知、托盘、提示音未做**：按既定决策属于 M8。

## 起不来怎么办

### 窗口没出现，日志里有 WebView2 错误

如果上一次 `pnpm tauri dev` 没有被正常结束，残留的 `ircuit.exe` / WebView2 进程会占着
用户数据目录，下一次启动就会以 `0x800700AA 请求的资源在使用中` 失败——**后端其实是连上的**
（日志里会看到 `registered nick=...`），只是窗口没建出来，所以很容易误判成「连接坏了」。

先结束残留进程：

```powershell
Get-Process ircuit -ErrorAction SilentlyContinue | Stop-Process -Force
```

仍然不行，就给这次运行换一个数据目录：

```powershell
$env:WEBVIEW2_USER_DATA_FOLDER = "$PWD\.cache\webview2"
pnpm tauri dev
```

### 端口被占

mock 默认监听 6667。如果该端口已被占用，换一个：

```bash
pnpm mock --port 6668
```

客户端里填 `127.0.0.1` / `6668` 即可。

### cargo 去连真实 registry 而卡住或报 TLS 错

`pnpm tauri dev` 直接调用 `cargo`，不会经过 `scripts/run-cargo.mjs`。在依赖已经拉全的
机器上没问题；如果报 `schannel: AcquireCredentialsHandle failed`，先跑一次
`pnpm mock`（它走包装脚本，会带上 `CARGO_HOME`），或者显式设置：

```powershell
$env:CARGO_HOME = "$PWD\.cache\cargo"
```
