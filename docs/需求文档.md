## 1. 项目定位

**Ircuit** — 现代、简洁美观、功能完整的桌面 IRC 客户端。

一句话卖点：**IRC 的协议深度 + 现代 IM 的界面品质 + 纯本地的历史与全文搜索。**

差异化（相对 HexChat / mIRC / WeeChat / Halloy / Konversation）：

| 维度 | 传统客户端 | Ircuit |
| --- | --- | --- |
| 界面 | 90 年代控件风格，信息密度高但粗糙 | 现代设计语言，留白与可读性优先 |
| 协议 | 多为 IRCv2 + 少量 IRCv3 | 完整 IRCv3（chathistory / read-marker / reply / reactions） |
| 历史 | 本地文本日志，难检索 | SQLite 持久化 + FTS5 全文搜索 + 无限上滑 |
| 扩展 | 脚本语言各有门槛 | JS 插件 API（QuickJS 沙箱）+ 主题系统 |
| 网络环境 | 有限 | 代理、客户端证书、Bouncer、多编码全支持 |
| 存储 | 明文配置 | 凭据进 OS Keyring，无遥测，纯本地 |

## 2. 技术选型

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 外壳 | **Tauri 2.x** | 体积小、原生性能、三平台；父目录即 `D:\Project\Tauri` |
| 后端 | **Rust** | 连接与协议放后端，才能做到常驻、IRCv3、DCC、本地库 |
| 异步/网络 | `tokio` + `tokio-rustls` + `rustls-platform-verifier` | 高并发连接、系统证书链 |
| 存储 | `rusqlite`（bundled）+ FTS5 | 单文件、零部署、全文检索 |
| 凭据 | `keyring` | Windows Credential Manager / macOS Keychain / libsecret |
| 编码 | `encoding_rs` + `chardetng` | 全编码支持 + 自动检测，纯 Rust |
| 插件沙箱 | `rquickjs`（QuickJS） | 快、小、易嵌入，天然无 IO 权限 |
| DCC | 自研（`tokio` TCP 监听） | 需要 RESUME、被动模式、进度控制 |
| IPC | `tauri-specta` + `specta` | Rust 类型自动生成 TS 类型，前后端契约不漂移 |
| 前端 | **React 19 + TypeScript + Vite** | 虚拟列表 / 编辑器 / 无障碍生态最成熟 |
| 样式 | **Tailwind CSS v4 + shadcn/ui (Radix)** + 自研 design token | 无障碍基线 + 可控视觉 |
| 状态 | `zustand` | 轻量、事件驱动友好 |
| 长列表 | `@tanstack/react-virtual` | 万级消息 60fps |
| 输入框 | CodeMirror 6 | 多行 + 命令语法高亮 + 补全 |
| i18n | `i18next` | zh-CN / en |
| 测试 | `vitest` + `cargo test` + Playwright | 协议层必须单测 |

## 3. 架构分层

```
┌─────────────────────────────────────────────┐
│  React 前端（纯 UI，不含协议逻辑）            │
│  buffers / messages / members / settings     │
└──────────────┬──────────────────────────────┘
               │ tauri-specta commands  +  event stream
┌──────────────▼──────────────────────────────┐
│  Rust Core                                   │
│  ├─ irc-proto    RFC1459 解析/序列化 + IRCv3 tags │
│  ├─ irc-client   连接状态机 / CAP 协商 / SASL / 重连 │
│  ├─ irc-state    network·channel·user 状态      │
│  ├─ storage      SQLite 历史 + FTS5 + 配置      │
│  ├─ encoding     编码检测与转换                  │
│  ├─ dcc          DCC CHAT / SEND / RESUME       │
│  ├─ plugin       QuickJS 宿主 + 插件 API        │
│  └─ commands     Tauri 命令层                   │
└─────────────────────────────────────────────┘
```

设计原则：

1. **前端不碰 socket**，只消费事件、发送意图；换 UI 框架不动协议层。
2. **协议层有独立单测**，用 RFC 样例与真实服务器流量做回归。
3. 事件采用「增量 + 环形缓冲」，避免长会话内存膨胀。

## 4. 功能清单（v1.0 范围）

### P0 — 核心

**连接与协议**
- 多网络并行连接；网络配置增删改、一键连接
- TLS（默认开启 + 证书校验）、自签证书例外
- SASL：PLAIN / EXTERNAL / SCRAM-SHA-256；服务器密码；NickServ 自动识别
- 自动重连：指数退避、连接风暴保护、会话恢复
- IRCv3 caps：`message-tags` `server-time` `batch` `echo-message` `multi-prefix` `away-notify` `account-tag` `extended-join` `chghost` `cap-notify` `sasl` `draft/chathistory` `draft/read-marker` `draft/reply` `draft/reactions` `draft/multiline` `labeled-response` `standard-replies`

**会话 UI**
- 左侧网络/频道树（折叠、排序、未读徽标、活动高亮）
- 中部消息流；顶部频道名 + Topic（可折叠）
- 右侧成员列表（按前缀/身份排序，可隐藏）
- 标签栏 / 快速切换

**消息渲染**
- IRC 格式码：粗体、斜体、下划线、删除线、等宽、mIRC 颜色、hex 颜色
- 时间戳、日期分隔线、连续消息分组
- 链接自动识别；服务器/自己消息视觉区分
- 无头像协议 → 昵称首字母色块 / identicon
- 提及高亮（自己的昵称、可配置关键词/正则）

**输入区**
- 多行输入、Enter 发送 / Shift+Enter 换行（可配置）
- Tab 昵称补全（最近发言者优先）、命令补全
- 完整 `/` 命令集：join part me msg query notice nick whois away back topic mode kick ban unban op deop voice invite ignore raw quit server clear close
- 输入历史（上下键）、草稿按 buffer 保存

**频道与用户操作**
- 频道模式面板、ban 列表编辑
- 用户右键菜单：WHOIS / 私聊 / OP / Voice / Kick / Ban / 忽略
- 邀请、被邀请提示

**通知**
- 桌面通知、任务栏/托盘提示、托盘红点
- 关键词高亮规则引擎、按 buffer 静音
- 声音提醒（可配）

**本地数据**
- SQLite 持久化全部消息；重启后恢复 buffer 与草稿
- 无限上滑分页加载
- FTS5 全文搜索（跨 buffer、可跳转原文）
- 日志导出（纯文本 / HTML）

**外观与设置**
- 深色 / 浅色 / 跟随系统
- 主题（CSS 变量 token），可自定义配色与字号
- 紧凑 / 舒适两种密度
- 设置界面：网络、外观、通知、快捷键、高级
- 快捷键系统（可重绑）
- 命令面板（Ctrl+K）

### P1 — 强大（**已确认全部纳入 v1**）

- **DCC**：CHAT + 文件传输（SEND / RESUME / ACCEPT / 被动模式），进度与断点续传
- **JS 插件系统**：QuickJS 沙箱，事件钩子 + 自定义命令 + 侧边栏面板 + 设置页扩展 + 白名单网络请求
- **粘贴图片/文件上传**：DCC SEND 或 HTTP 图床（0x0.st / catbox / 自建 / 自定义 PUT），用户可选
- **IRCv3 高级**：消息回复 `draft/reply`、Reaction `draft/reactions`、`draft/chathistory` 历史拉取、`draft/read-marker`、`draft/multiline`
- **网络环境**：SOCKS5 / HTTP 代理、客户端证书（SASL EXTERNAL）、自签证书例外
- **Bouncer**：ZNC / soju 的 playback 与 buffer 语义
- **编码**：完整编码选择器，UTF-8 默认 + 自动检测 + 按网络/频道覆盖
- **配置导入**：HexChat / mIRC / WeeChat
- 内联图片/附件预览、拖拽发送
- 分屏、可拖拽面板、多窗口
- 忽略/黑名单与反垃圾规则
- 主题市场、自动更新、i18n（zh-CN / en）
- 无障碍：全键盘操作、屏幕阅读器语义、WCAG 2.2 AA

### P2 — 以后再说

移动端、多协议桥接（Matrix/XMPP）、云同步、AI 助手（频道摘要/翻译）、语音。

## 5. 界面方向

- **三栏布局**：网络/频道树 · 消息流 · 成员列表，两侧均可收起。
- **消息流是绝对主角**：不加多余装饰，靠字重、间距、颜色区分层级。
- 视觉语言：中性底色 + 单一强调色 + 语义色（提到我 / 错误 / 系统）；圆角克制、阴影仅用于浮层。
- 支持纯键盘走完全部流程。
- 避免「模板感」：不堆渐变、不用默认组件库外观、不照搬 Discord 布局记忆。

## 6. 非功能需求

| 项 | 目标 |
| --- | --- |
| 性能 | 10 万条消息滚动稳定 60fps；20+ 网络并行；空闲内存 < 300MB |
| 可靠性 | 断线自动重连；echo-message 去重；消息本地队列不丢 |
| 安全 | TLS 默认开、证书强校验、凭据入 Keyring、插件默认零权限、无遥测、无外联 |
| 隐私 | 所有数据仅存本地；导出/清除数据可控 |
| 代码质量 | TS strict、Rust clippy deny warnings、协议层单测覆盖 |
| 可维护 | 协议层与 UI 层零耦合；IPC 类型自动生成 |
